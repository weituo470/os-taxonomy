# Locale overlays

English is the source of truth for the Marble Skill Taxonomy. Topic IDs, prerequisite edges, subject and domain keys, ages, standards and curriculum codes stay in the English JSON files under [`data/`](../data/). A locale is an overlay of Marble-authored user-facing prose. It does not fork the graph.

The interactive curriculum map at [withmarble.com/curriculum](https://withmarble.com/curriculum) is a downstream site. This repository excludes visualizations (`data/manifest.json`). The locale files are the contract that site, or any other consumer, can load. There is no second map UI in this repo, and the Marble Builder examples are separate learning activities, not this dataset.

## What is translated

| English source | Locale file | Translated fields | Join key, left in English |
|---|---|---|---|
| `data/topics.json` | `topics.json` | `name`, `description`, `evidence`, `assessmentPrompt` | `id` |
| `data/dependencies.json` | `dependencies.json` | `reason` | `topicId`, `prerequisiteId` |
| `data/clusters.json` | `clusters.json` | `summary` | `subject`, `domain`, `ageRangeStart` |
| subject, domain, type and strength labels | `messages.json` | display labels | the English keys themselves |

`messages.json` also carries suggested labels for a curriculum-map language switcher (`labels.switchLanguage`, `labels.languageName`, `labels.draftNotice`, and the panel labels). Those strings are part of this overlay because the site source is not in the repository. They are not a transcript of the live site.

Records stay in the same order as the English file. An evidence array keeps the same length. `{{name}}` stays exactly `{{name}}`, and it occurs the same number of times. Arabic numerals and mathematical symbols (`%`, `°`, `×`, `÷`, `²`, `³`, `√`, `π`, `≤`, `≥`, `≈`, and currency signs) are copied as written. A thousands comma is part of the numeral (`4,213`). A comma after a year or a list item is sentence punctuation and need not be copied. Short acronyms such as `DNA` or `Scratch` may remain in Latin script inside a Chinese sentence.

## What is not translated

These files stay under their existing provenance rules and are not copied into a locale:

- `data/curriculum-standards.json` — third-party curriculum wording. Some sources are codes only. Translating them would be a new copy of someone else's text, under that source's licence, not under Marble's CC BY-SA licence.
- `data/teaching-research.json` and `data/archived-teaching-research.json` — Marble-authored, but they quote and cite third-party research and are outside the curriculum-map strings this overlay covers. A later locale can add them under the same overlay rules.
- `data/curriculum-alignments.json` — IDs, scopes and standard keys, not prose to translate.
- Reports under `reports/` — historical authoring notes.

Subject and domain strings inside a cluster or message key are identifiers. Translate the label in `messages.json`; do not replace the key with Chinese.

## Layout

```text
data/locales/catalog.json
data/locales/zh-CN/topics.json
data/locales/zh-CN/dependencies.json
data/locales/zh-CN/clusters.json
data/locales/zh-CN/messages.json
```

`catalog.json` lists each locale and the SHA-256 of those four files. `data/manifest.json` continues to hash the English canonical files only.

Locale identity for the first overlay:

| Field | Value |
|---|---|
| `locale` | `zh-CN` |
| `language` | `zh-Hans` |
| `status` | `community-draft` |
| `reviewStatus` | `needs-native-speaker-review` |
| `translationMethod` | `ai-assisted` |

`zh-CN` is the BCP 47 tag a switcher stores. `zh-Hans` records the script. Each content file repeats the licence and a review notice so the file still explains itself if it is copied alone.

## Review status

The Simplified Chinese text is a community/AI-assisted draft. It has not had native-speaker review for teaching accuracy. Consumers must show `labels.draftNotice` while `status` is `community-draft`. The English sentence remains the canonical claim. A reviewer who accepts the wording sets `status` to `reviewed` and `reviewStatus` to `native-speaker-reviewed`, and rewrites the notice in every locale file so they stay identical.

## How a consumer loads a locale

The public site can offer English plus every `catalog.json` entry. English needs no overlay. For another locale, join by ID and keep every field the overlay does not carry.

```js
import topics from './data/topics.json' with { type: 'json' };
import overlay from './data/locales/zh-CN/topics.json' with { type: 'json' };
import messages from './data/locales/zh-CN/messages.json' with { type: 'json' };

const byId = new Map(overlay.records.map((record) => [record.id, record]));

function localizeTopic(topic) {
  const text = byId.get(topic.id);
  return {
    ...topic,
    name: text.name,
    description: text.description,
    evidence: text.evidence,
    assessmentPrompt: text.assessmentPrompt,
    subjectLabel: messages.subjects[topic.subject],
    domainLabel: messages.domains[topic.subject][topic.domain],
    typeLabel: messages.topicTypes[topic.type],
  };
}
```

Dependency reasons join on `topicId` plus `prerequisiteId`. Cluster summaries join on `subject`, `domain` and `ageRangeStart`. Strength stays `hard` or `soft`; the visible word is `messages.dependencyStrengths`.

A language switcher should:

1. Read `data/locales/catalog.json`.
2. Offer English and each locale's `endonym` (`简体中文` for `zh-CN`). Label the control with `labels.switchLanguage`.
3. When a non-English locale is selected and its `status` is `community-draft`, show `labels.draftNotice` next to the translated text.
4. Leave topic IDs, edges and standard codes unchanged.

`node scripts/localize.mjs zh-CN mt_N8CpN1EJrP` prints one merged topic for inspection. It is a maintainer tool, not the site.

## Checks

Registered locales have to cover every current English record. Validation fails if an ID is missing, extra, or out of order, if English prose changed under the overlay, or if a translated string drops a numeral, symbol or `{{name}}`. The binding is a SHA-256 of the translatable English fields, not of the whole English file, so a standards-link or checksum edit does not by itself invalidate a translation. Editing a name, description, evidence item, assessment prompt, reason or summary does.

```bash
node scripts/check-locales.mjs --print-projections
npm run locales:check
npm run validate
npm test
```

`npm run validate` checks locales when `data/locales/catalog.json` is present. `npm run locales:check` requires the catalog. After editing locale bytes, refresh the catalog hashes without touching projection hashes:

```bash
node scripts/check-locales.mjs --stamp-files
```

`--stamp-files` does not mean the translation was reviewed. It only records the new file bytes.

## Add a language

1. Copy `data/locales/zh-CN/` to `data/locales/<locale>/`, using a regional tag such as `fr-FR`.
2. Set `locale`, `language` and `endonym`. Keep `sourceLocale` as `en`.
3. Translate every record in place. Do not add topics, edges, subjects or standards. Keep English join keys.
4. Put the user-facing review notice in `labels.draftNotice`, and copy that same string to `reviewNotice` on every file.
5. Keep `contentLicense` as `CC-BY-SA-4.0` and `databaseLicense` as `ODbL-1.0`. Say in `attribution` that the text is a translation, that it needs native-speaker review until it has had one, and include `CC BY-SA 4.0`.
6. Recompute `sourceProjectionSha256` from `--print-projections` if the English text has moved, then register the directory in `data/locales/catalog.json`.
7. Run `node scripts/check-locales.mjs --stamp-files`, then `npm run validate` and `npm test`.

A partial locale does not pass. When English gains a topic or a reason changes, update the overlay in the same change or a follow-up that restores a green check.

`node scripts/check-locale-slice.mjs topics source.json translated.json` checks one array before it is merged. `kind` is `topics`, `dependencies` or `clusters`.

## Terms for Simplified Chinese

Normative subject, domain, type and strength labels are in [`data/locales/zh-CN/messages.json`](../data/locales/zh-CN/messages.json). Further translations should reuse these when the same English term appears:

| English | Simplified Chinese |
|---|---|
| phoneme / grapheme | 音素 / 字素 |
| digraph / trigraph | 二合字母 / 三合字母 |
| blend | 辅音连缀 |
| sight word | 高频词 |
| place value | 位值 |
| number bond | 数的分合 |
| number line | 数轴 |
| array (multiplication) | 阵列 |
| regroup | 重组（进位或退位） |
| numerator / denominator | 分子 / 分母 |
| equivalent fractions | 等值分数 |
| equation with an unknown | 方程 |
| number sentence | 等式 |
| bar chart / pie chart / line graph | 条形图 / 饼图 / 折线图 |
| mean / median / mode | 平均数 / 中位数 / 众数 |
| mass / weight | 质量 / 重量 |
| fair test | 公平测试 |
| habitat | 栖息地 |
| producer / consumer | 生产者 / 消费者 |
| minibeast | 小生物（小型无脊椎动物） |
| transcription (writing) | 誊写，不是语言翻译 |
| Year 1 / Grade 1 / Y1 / KS1 | keep the token, and gloss it on first use: 一年级（Year 1）、一年级（Grade 1）、Y1、KS1（英国关键阶段 1） |
| Foundation | 基础年级（Foundation） |

Use mainland simplified characters and school terms (信息科技, 程序, 软件). Prefer `{{name}}` over 他 or 她. Parent-facing cluster summaries can address 孩子. Do not add examples that the English sentence does not contain.
